# H7 log: accents, wave page titles, loaders

## What changed

**Tokens (`web/src/app/globals.css`, `web/docs/DESIGN.md`)**
- Added `--cobalt`, `--cobalt-deep`, `--amber`, `--amber-deep` for light and dark, exposed as `bg-cobalt`, `text-cobalt-deep`, `border-cobalt`, `bg-amber`, `text-amber-deep` and so on.
- Light values are as briefed, except amber-deep. `#A85A10` reaches only 4.39:1 on paper and 3.94:1 on the sunk surface, so the token is `#944E0E` (5.41:1 paper, 4.85:1 sunk, 5.90:1 raised).
- Dark values are as briefed: cobalt `#7C97FF` (6.95:1 on dark paper), cobalt-deep `#A9BBFF` (10.1:1), amber `#F0A85A` (9.4:1), amber-deep `#F7C48A` (11.9:1).
- Amber is a fill colour, not text colour. Amber on light paper is 2.38:1, so it is used as a fill with ink text (6.85:1).
- DESIGN.md has an accent roles section: vermilion is the focal accent, cobalt is for information and live status, amber is for caution. It also documents the new tokens and removes wording about "the kit" in my scope.
- Links underline in cobalt on hover (`a:hover` in the base layer).

**UI components (`web/src/components/ui/`)**
- `badge.tsx`: new tones `live` (cobalt fill, breathing dot), `info` (cobalt outline) and `caution` (amber fill). `accent` stays vermilion for danger and errors.
- `stat.tsx`: optional `tone` ("info" or "caution") for the mark beside the label when not `focal`.
- `meter.tsx`: tones `info` (cobalt) and `caution` (amber).
- `state.tsx`: `LoadingState` uses the `ScrambleLabel` text loader instead of a blinking square. `Notice` warning uses amber, info uses cobalt.
- `page-header.tsx`: a level 1 string title renders through `WaveText` (`headingAs="h1"`). It keeps the headline as a real h1, and WaveText's inert water copy is aria-hidden. Overrides compact the hero into a header band (`!`-prefixed arbitrary variants, because `wave-text.css` is unlayered). Eyebrow shows `index / eyebrow`. Actions and children render below the band. Non-string titles or descriptions, and level 2, use the plain layout. The `id` prop applies only to the plain layout. Level 2 eyebrows use a cobalt mark. `SectionHeading` index numbers use cobalt.

**Pages and loading files (in scope)**
- Loading files now all point at `PageLoader` with a label: `app/loading.tsx`, `candidate/loading.tsx`, `candidate/exams/[examId]/loading.tsx`, `candidate/results/[attemptId]/loading.tsx`, `examiner/questions/loading.tsx`. `error/[code]/loading.tsx` already used it.
- PageHeader adopted in: `app/page.tsx` (no-role account page), `examiner/exams/page.tsx` (02 / Exams), `examiner/exams/new/page.tsx` (01 / Create, with breadcrumb), `examiner/questions/page.tsx` (01 / Question bank, with Import and New question actions), `examiner/questions/import/page.tsx` (03 / Import, with breadcrumb), `settings/page.tsx` (01 / Account, with breadcrumb), `examiner/exams/[examId]/results/results-view.tsx` (level 2 header, actions kept), `(admin)/admin/users/users-admin.tsx` (01 / Administration). The users admin "Loading activity" plain text is now a `BrailleSpinner`.
- `error/[code]/page.tsx`: removed a "kit" mention from a comment.
