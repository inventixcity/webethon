You own the monitor-stream addition in `backend/crates/exam_integrity/**` and the bulk-credit addition in `backend/crates/exam_resilience/**`, plus migrations `20261127002300_*` if needed. Read handoff/HANDOFF.md ("PHASE 2", section 5), the existing monitor endpoint in exam_integrity and the time-credit logic in exam_resilience.

1. GET `/exams/{id}/monitor/stream` (exam owner):
   - Server-Sent Events (`text/event-stream`; axum `Sse` with keep-alive).
   - Emit `event: snapshot` with data = the same JSON as GET /exams/{id}/monitor (`ExamMonitor`, without the `{data}` envelope) immediately, then every 3 s, but only when it changed since the last emit (hash compare); send a comment keep-alive every 15 s.
   - Stop after 30 minutes (the client reconnects). Re-check the session and ownership every 60 s, closing on failure.
   - Cap at 5 streams per examiner (an in-memory counter is fine; document it) with 429 beyond that.
   - Make sure the server's request timeout middleware doesn't kill the stream. Check how backend/crates/server/src/lib.rs applies timeouts. The realtime crate already handles SSE: read it and follow its approach for exempting stream routes.
2. POST `/exams/{id}/outage-credit {from, to, reason}` (exam owner or admin):
   - from < to; the window is at most 2 h and inside the exam window; reason 3–500 chars.
   - For every in_progress (or expired within the last 30 min) real attempt of the exam, compute its VERIFIED outage overlap with [from, to] using the existing heartbeat-gap logic (gaps ≥ 45 s). Grant exactly the uncredited overlapping seconds via the existing time-credit path (same caps: never beyond ends_at + 60 min; audited `exam.time_credit` per attempt with a `bulk: true` meta).
   - Attempts with no verified gap in the window are skipped.
   - Return `BulkCreditResult {credited, skipped, secondsTotal}`. One transaction, with a per-attempt row lock.
   - Rate limit at 10/hour per examiner.
3. Tests: the stream route requires the owner (404 for others); the snapshot JSON matches the monitor shape; bulk credit grants only verified overlap, skips the others, respects the caps, and is audited; a candidate gets 403/404.
4. fmt, clippy (`--all-targets -- -D warnings`) and tests for both crates.
