# C15: AI grading assistant (backend, optional and privacy-preserving)
You own the crate `backend/crates/exam_assist/**` (the lead already scaffolded it, registered it in the workspace and mounted it in the server; fill it in) and migrations `20261127002200_*` if needed. Read handoff/HANDOFF.md ("PHASE 2", section 5) and the PHASE 2 `GradingSuggestion` type.

1. Config from env (read once): `AI_API_KEY`, `AI_BASE_URL` (default `https://generativelanguage.googleapis.com/v1beta/openai`), `AI_MODEL` (default `gemini-2.5-flash`). If no key is set, the endpoint returns 404 with code NOT_CONFIGURED (`kernel::ErrorCode::NotConfigured`), and the UI hides the button.
2. POST `/attempts/{attemptId}/answers/{itemId}/suggest` (exam owner of that attempt's exam via load_exam_for_examiner; written items only; the attempt must be finalized):
   - Build the prompt from ONLY: the question stem, the rubric, the max marks and the candidate's answer text. Never send the name, email, ids or other answers.
   - Strip zero-width characters (the watermark) from the stem. Truncate the answer to 6000 chars.
   - Call the OpenAI-compatible `POST {base}/chat/completions` with `state.http` (reqwest), a 20 s timeout and `response_format: {type: "json_object"}`. Use a system prompt telling the model to act as a strict, fair examiner and return JSON `{suggestedMarks:number, rationale:string (≤600 chars), rubricHits:string[] (≤6)}`, never exceeding max marks, in 0.25 steps.
   - Validate and clamp the model output server-side; reject non-JSON with 502 UNAVAILABLE.
   - Rate limit at 60/hour per examiner. Audit `grading.ai_suggest` with no content.
   - The suggestion is advisory: NEVER write marks. The examiner saves through the normal grade endpoint.
3. Treat the model output as untrusted: no HTML; plain strings bounded in length.
4. Tests (no network): unit-test prompt building (no PII, watermark stripped), output parsing and clamping, NOT_CONFIGURED without a key, 404 for a non-owner, non-written item rejected. Put the HTTP call behind a small trait or function so tests stub it.
5. fmt, clippy (`--all-targets -- -D warnings`) and tests.
Finish with `STATUS: COMPLETE` as the last line of handoff/log/C15.md.
