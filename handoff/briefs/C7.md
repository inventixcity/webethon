# C7: exam_integrity (3.6 monitoring + 5.1 Integrity in the AI era): server and browser signal collector
Principle: privacy-light (no webcam, no microphone, no screen capture, no keystroke contents), transparent to candidates, and **indicators, never verdicts**.

## Backend: `backend/crates/exam_integrity`

**`POST /attempts/{id}/events {events: IntegrityEventInput[]}`** (attempt owner, in_progress or within 2 min of the deadline):
- At most 50 events per batch; rate limit at 30 batches/min per attempt.
- Validate: kind in the client-allowed list (from `IntegrityEventKind` in types.ts); detail is a flat object of at most 8 keys, each key `^[a-zA-Z]{1,24}$`, values a string (<= 64 chars), a number or a bool; durationMs 0..86400000.
- Map severity:
  - warning: paste with pastedChars >= 200, fullscreen_exit, a single focus_lost lasting >= 30 s
  - notice: other focus_lost, visibility_hidden, copy
  - info: everything else
- Insert into attempt_events with client_at (informational), then recompute `attempts.review_priority` (below). Return `{recorded}`.

**Review priority** (`pub async fn recompute_priority(conn, attempt_id)`). Compute a weighted score over the attempt's events and answers:
- each focus_lost or visibility_hidden over 10 s: +1, capped at 6
- fullscreen_exit: +1 each, capped at 4
- large paste (>= 200 chars): +2 each
- canary_hit: +5
- device_takeover: +1
- typing_anomaly: +2 (computed from answers.typing: a written answer where `pastedChars > 0.6 * len` or `keystrokes < 0.3 * len` for len >= 150)
- speed_anomaly: +2 (computed in analytics; skip here)
- Thresholds: 0 → none, 1-3 → low, 4-7 → medium, 8+ → high.
- Typing check: also run it on `PUT answers` indirectly: expose `pub fn typing_flag(len, typing) -> bool` and have the integrity report compute it. Don't modify C4's crate.

**Canary**: `pub fn canary_hit(text, word) -> bool` (case-insensitive word boundary). In the integrity report, check the written answers against `exam_attempts::canary_word(exam_id)`. Don't depend on exam_attempts; re-derive the same word with the same algorithm from the same 20-word list. Coordinate by reading C4's code; if it isn't there yet, define the list as specified in C4's brief and note it in your log. Count canary hits as indicators.

**`GET /attempts/{id}/integrity`** (exam owner): `IntegrityReport`.
- indicators: plain-language labels and explanations, e.g. "Left the exam window 4 times (total 2m 10s)".
- events: newest first, limit 500.
- outages: compute the heartbeat gaps (>= 45 s) the same way C5 does (a small local SQL; mark credited if a time_credits row overlaps).
- Always include `disclaimer: "Indicators support human review. They are not evidence of misconduct."` (add the field; the lead will add it to types).

**`GET /exams/{id}/monitor`** (owner): `ExamMonitor`.
- Real attempts only. online = last_heartbeat_at within 40 s.
- answered = answers with a non-empty response; flagged count; incidents = notice + warning events.
- Counts: enrolled, notStarted, inProgress, submitted.
- One efficient SQL query with lateral aggregates (it's polled every 5 s by many examiners).

**Announcements**:
- `POST /exams/{id}/announcements {body 1-1000}` (owner): rate limit at 10/min, audited.
- `GET /exams/{id}/announcements` (owner, or an enrolled candidate).

**`POST /exams/{id}/trace {text}`** (owner): leak tracer.
- Find U+2060-framed sequences of U+200B/U+200C in the pasted text (<= 20000 chars) and decode the 64 bits as the first 8 bytes of an attempt id. That's C4's watermark scheme; read C4's `watermark` doc comment.
- Match `attempts` of this exam where the first 8 bytes of the id equal the decoded bytes (`substring(uuid_send(id) from 1 for 8)`).
- Return `{attemptId, candidate: {displayName, email}} | null`. Audit `integrity.trace`.

Tests: event validation and caps; priority thresholds; trace roundtrip (implement a local encoder in tests with the same scheme); monitor excludes sandbox; a candidate can't read monitor (403/404).

## Web: `web/src/lib/exam/integrity.ts`
`startIntegrity({attemptId, deviceId, settings, onWarning})` returns a `stop()` function. Collect:
- `visibilitychange` and `blur`/`focus`, with durations
- fullscreenchange exits (only if settings.integrity.fullscreen)
- `paste` on the exam root (pastedChars = clipboard text length; never send the content)
- `copy`, `contextmenu`
Batch events every 5 s or at 20 events, POST `/attempts/{id}/events` with the `X-Attempt-Device` header, and use `navigator.sendBeacon`-style keepalive fetch on pagehide.

Also export `useTypingTelemetry()`, which returns handlers `{onKeyDown, onPaste}` and `snapshot()` → `{keystrokes, pastes, pastedChars, activeMs}` per written item, for H2 to pass into setAnswer's typing argument.

And export `requestExamFullscreen(el)` and `CANDIDATE_NOTICE`: a plain-language transparency string listing exactly what is collected, shown in the lobby and workspace.
